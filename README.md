# Innovation Digitale : cours et canevas de projet

Cours d'innovation digitale, accompagné d'un canevas Excel qui aide les étudiants à choisir leur thème et à structurer leur projet, de l'idée jusqu'au suivi des résultats.

---

## Plan du cours

| Module | Titre | Contenu principal |
|---|---|---|
| M1 | Innovation | Invention et innovation, 4 types, rupture, courbe d'adoption |
| M2 | Le numérique | Numérisation, digitalisation, technologies, maturité |
| M3 | Stratégie | Golden Circle, Océan Bleu, ERAC, valeur ajoutée, SWOT |
| M4 | L'utilisateur | Design Thinking, entretiens, personas, parcours |
| M5 | Cadrage | Existant, Ishikawa, problématique, objectifs, variables, besoins |
| M6 | Agilité | Cycle de vie, Scrum, user stories, MoSCoW, MVP, roadmap |
| M7 | UI/UX | Concepts, moments d'intervention, Nielsen, accessibilité, design system |
| M8 | Du design au code | UML, architecture, BaaS, API, tests, CI/CD |
| M9 | Éthique et mesure | Données personnelles, KPI, OKR, conduite du changement, projet final |

Les travaux dirigés (TD 1 à 4) et pratiques (TP 1 à 4) sont intégrés aux modules.

## Utiliser le canevas Excel

### Les couleurs

| Couleur | Signification |
|---|---|
| Jaune | Cellule à remplir par l'étudiant |
| Gris, en italique | Exemple à remplacer par votre contenu |
| Bleu | Formule automatique, à ne pas modifier |

### Choisir son thème (feuille 2)

1. Listez vos idées de thème dans le tableau (10 au maximum)
2. Notez chaque idée de 1 (très faible) à 5 (excellent) sur les 6 critères
3. Lisez le **score sur 100**, le **rang** et la **décision** calculés automatiquement
4. Validez le thème le mieux noté avec l'enseignant

Décisions : un score de 70 ou plus donne **Retenir**, entre 50 et 70 **À affiner**, sous 50 **Abandonner**. Les poids des critères sont modifiables, leur total doit rester égal à 100.

### Bonnes pratiques

- Ne supprimez pas et ne renommez pas les feuilles : certaines formules en dépendent
- Effacez ou remplacez les lignes d'exemple grises
- Enregistrez une copie du fichier par groupe, avec le nom du groupe dans le nom du fichier
